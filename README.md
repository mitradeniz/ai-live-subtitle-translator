# AI Live Subtitle Translator

An open-source browser extension for translating video subtitles while you watch, with Google Translate and bring-your-own-key AI translation options.

The project is in early development. There is no installable release yet.

The first target is desktop Chrome and Edge, starting with videos that already have accessible captions. Translation will run through the selected provider without a project-operated server. Keyless Google integration is being evaluated; availability is not yet verified.
